## 1. 交易设置

### 入场计划(三段式 — 优先等回踩)

| 触发类型 | 价位 | 触发条件 |
|----------|------|----------|
| **保守入场(首选)** | **$77.00-78.50** | 峰会后回踩至分析师均价 PT 区域,量缩企稳 → 主仓位 40-50% |
| **激进入场(突破)** | **$82.50+** | 日线收盘 > $82.50 放量(volume > 1.3x 30日均量)→ 主仓位 30% |
| **加仓 1** | **$74.00** | 跌至 JPM PT + 突破前平台 → 加 20-30% |
| **加仓 2** | **$71-72** | 跌至 50日均线/200日均线汇合区(深回踩)→ 加 20% |
| **不入场区** | **$83-85** | 短期超买,等回落或放量突破 $85 |

**入场逻辑**:
1. **均价 PT 是天然吸筹位**: $77.00 = 分析师 consensus $76.17 上方,机构会主动接盘。
2. **峰会后 sell-the-news 回落给机会**: 即使峰会顺利,股价短期可能回踩 $77-78 → 这是最佳进场窗口。
3. **结构性突破 = 趋势加速**: 若放量突破 $82.50 → 进入"无阻力区",目标 $85-90。
4. **不追高的纪律**: 当前价 $81 = 52周新高,已超均价 PT,直接追=R/R 难看。

**最佳入场时点**:
- **5/16 周一 — 5/22 周五**:看峰会消息发酵 → 寻找 $77-78 区域的支撑信号(量缩、十字星、锤子线)
- **5/20 除息日(派息 $0.52)**:股价自动 -$0.52,可能短暂砸出便宜筹码 → 适合首次建仓
- 不要在峰会期间(5/14-15)入场,等噪声出清

## 2. 期权方案(适用中短期 + 杠杆放大)

✅ **ADM 多头适合用期权放大收益**:IV ~26-27% 中等,call debit spread 性价比好。

| 策略 | 细节 | 单张成本(估算) | 最大收益 | 盈亏平衡 |
|------|------|-----------------|----------|----------|
| **首选 Call Debit Spread(中)** | 买 7/17 $80C / 卖 7/17 $87.5C | ~$300-350 / 张 | $400-450 / 张 | $83.0-83.5 |
| 激进 Wide Call Spread | 买 7/17 $80C / 卖 7/17 $92.5C | ~$420-470 / 张 | $780-830 / 张 | $84.2-84.7 |
| 单腿买入认购 | 买 7/17 $80C | ~$350-400 / 张 | 无限 | $83.5-84.0 |
| **激进价差 + 远月** | 买 9/19 $80C / 卖 9/19 $95C | ~$580 / 张 | $920 / 张 | $85.8 |
| Bull Put Spread(收取权利金) | 卖 7/17 $75P / 买 7/17 $70P | 净收 ~$80 / 张 | $80 / 张 | $74.2 |

**期权选择理由**:
- **IV ~26-27%** 中等水平 → call debit spread 比裸买便宜约 30-40%,且风险有上限。
- **7/17 到期** 跨越:峰会(5/14-15)+ 除息(5/20)+ 8 月初 Q2 财报前(避免财报 IV 崩溃)。
- **9/19 远月**: 给 Q2 财报留时间 + 政策催化继续发酵窗口 → 更适合 high-conviction 长线交易者。
- **Bull Put Spread**: 在 $75 不破的情况下白拿权利金,**适合"我看不太跌但也不强烈看涨"的中性偏多观点**。

**实际下单示例**(中等账户 $50K,中线多头):
- **基础仓**: 30 股股票 @ $78 = $2,340
- **杠杆仓**: 3 张 7/17 $80/$87.5 Call Debit Spread = $900-1,050
- 总成本 ~$3,300,占账户 6.6%
- 最大潜在收益:股票部分 $360(T1)~ $660(T2)+ 期权部分 ~$1,200-1,350
- 最大潜在亏损:股票 -$150(止损)+ 期权全损 $1,050 = -$1,200(2.4% 账户)
