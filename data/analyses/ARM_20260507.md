## 5. 多空对比

**看多**
- Armv9 仅占授权费 25%；长期目标 60–70% 意味即使手机出货走软，每单元授权费金额仍能复利
- 数据中心才是真故事：$2B 订单积压、Cobalt 200 V3 量产、AWS Graviton/Google Axion 扩张。CSS 交易费率远高于传统 IP 授权
- 存储短缺是**暂时**的（12–18 月）—— HBM/DRAM 解堵后，智能手机授权费在更高 v9 费率基础上恢复增长
- 极小 ~10% 流通使任何正面意外（新 CSS 超大规模客户、NVIDIA/Apple 扩产）被放大
- 12.55% 空头比例为正面数据点设置轧空风险

**看空**
- Q4 授权费不及预期 + 显式智能手机负向指引直接攻击 +84% 涨幅核心论点
- 前瞻 P/E 110x 是行业中位 3 倍以上；任何减速触发严重估值压缩。历史先例：2025-12 -20% 跌幅
- 数据中心订单积压只锁定 H1 —— H2 供应不确定封顶上行指引
- SoftBank 持有 $20B 保证金贷款抵押 ARM + 需 OpenAI 资金；大型增发或被迫卖出阴影
- 股价刚创历史最高后跳空 —— 经典顶部塌陷设置
- 即使 $222，ARM 仍较 52 周低 +120%；获利了结弹药充足

## 6. 风险评估

| 风险 | 等级 | 说明 |
|------|------|------|
| 估值/估值压缩 | 极高 | 110x 前瞻 P/E 在"超预期但关键线不及"的财报中是教科书压缩设置 |
| 智能手机授权费减速 | 高 | 首次明确负向指引；存储短缺时点不确定 |
| SoftBank 阴影/保证金贷款反身性 | 高 | $20B 贷款抵押 ARM；下跌时被迫卖出风险 |
| 流通量/流动性风险 | 高 | ~10% 流通 = 双向波动、跳空风险 |
| 客户集中度 | 中 | NVIDIA、Apple、Qualcomm、MediaTek —— Qualcomm 诉讼风险延续 |
| 地缘政治（中国授权费） | 中 | 中国是重要授权费来源 |
| AI/数据中心放缓 | 低–中 | 订单积压强劲，但超大规模厂商资本开支峰值争议持续 |

**总体风险等级**：**高 → 极高** —— 在关键指标不及后于溢价倍数做多极不利。风险偏不对称 —— 利于做空或观望。

## 7. 结论

**方向偏好**：**短期看空 / 中期中性。** Q4 授权费不及预期 + 首次"智能手机转负"指引精准攻击 +84% 涨幅核心叙事。在 110x 前瞻 P/E 下，未来 4–8 周估值压缩空间大于上行惊喜空间。

**信念度**：**7/10**（在 $230–237 区间或跌破 $207 战术做空）。**4/10**（裸做空），因空头比例轧空风险 + 数据中心结构性顺风。

**建议持有期**：**2–8 周**战术做空。长期（12+ 月）v9 + CSS 数据中心故事完整，股价可能在更深回调至 $175–190 区间被重新买入。

**关键催化剂**：
- **下次授权费数据**（Q1 FY27 财报，2026 年 8 月初）—— 确认或否认智能手机"转负"指引
- **Cobalt 200 放量评论**（Microsoft）+ 新 CSS 超大规模客户（AWS、Meta、Oracle）
- **存储芯片供应正常化**（HBM/DRAM 交付周期数据）
- **SoftBank 资本动作** —— 任何二级发行或保证金贷款扩张 = 直接抛压
- **Armv9 占比更新**（下季财报）—— 需保持向 60–70% 目标推进
- **宏观 / NVIDIA 财报**（5 月底）—— 决定整个 AI 基础设施情绪
